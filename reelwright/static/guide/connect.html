Connecting your accounts

Every permission Reelwright asks for, why, and how to set each developer portal up. Reelwright runs on your computer and uses developer apps that you create, so each platform's permissions are granted to your app.

Claude (Anthropic)

No permissions to configure: an API key is all it needs.

  1. Sign in at console.anthropic.com and add billing.
  2. API keys → Create key, copy it.
  3. Reelwright → Settings → Claude AI → paste the key → Save. Settings → Diagnostics → Deep check confirms it works.

YouTube (Google Cloud)

Permissions (OAuth scopes) Reelwright requests

ScopeUsed for
https://www.googleapis.com/auth/youtube.uploadUploading videos and setting custom thumbnails
https://www.googleapis.com/auth/youtube.readonlyShowing your channel and reading view/like counts (learning from results)
https://www.googleapis.com/auth/youtube.force-sslMoving the publish time of a video that is already uploaded and scheduled

Setup

  1. Open Google Cloud Console and create a project (any name).
  2. APIs & Services → Library → search YouTube Data API v3 → Enable.
  3. Google Auth Platform → Branding (the OAuth consent screen): app name, your support email, developer contact. Audience: External.
  4. Data Access → Add or remove scopes: add the three scopes above (filter by “youtube”).
  5. Audience → Test users → Add users: add the Google account that owns your channel.
  6. Clients → Create client → Application type Desktop app → Create → Download JSON.
  7. Reelwright → Publish → YouTube → Upload client JSON → Sign in with Google → approve every permission.
Know before you post:
  • While the consent screen is in Testing, Google expires the sign-in after 7 days. Set the app to In production (Audience → Publish app) to keep it. Without Google verification you'll see an “unverified app” warning when signing in; that's fine for your own channel.
  • Until your project passes YouTube's API compliance audit, videos uploaded through the API are locked to private. Request the audit from the YouTube API Services form linked in Google Cloud.
  • Custom thumbnails need a channel verified by phone (youtube.com/verify).
  • The API has a daily quota (10,000 units by default) and uploads use a large share of it; request more in Google Cloud if you post a lot.
  • Connected before this version? Reelwright shows a notice: Disconnect and sign in again to grant youtube.force-ssl.

TikTok

Permissions (scopes) Reelwright requests

ScopeProductUsed for
user.info.basicLogin KitYour display name and avatar
video.publishContent Posting API (Direct Post)Posting videos to your profile, reading your posting options and post status

Setup

  1. Go to developers.tiktok.com → Manage apps → Connect an app.
  2. Fill in the app details: icon, name, category, description, and your public Terms of Service and Privacy Policy URLs (see Policy URLs). Under Platforms, choose Desktop.
  3. Add products → Login Kit. Under Redirect URI add exactly http://localhost:8765/oauth/tiktok/callback (the Publish page shows the exact value if you changed Reelwright's port).
  4. Add products → Content Posting API and turn on Direct Post.
  5. Scopes: make sure user.info.basic and video.publish are added.
  6. For testing before review, open Sandbox, create a sandbox and add your TikTok account as a target user.
  7. Copy the Client key and Client secret → Reelwright Publish → TikTok → Save app → Sign in with TikTok.
Until TikTok audits your app (Content Posting API audit, submitted from the developer portal with a demo of the posting screen): posts are Only me, your TikTok account must be set to private when posting, and at most 5 accounts can post per day. After the audit, the publish dialog offers every audience your account allows.

Instagram

Your Instagram account must be a Business or Creator account (Instagram app → Settings → Account type and tools). Meta offers two ways to get a token; Reelwright accepts either.

Route A — Instagram Login (simplest, no Facebook Page)

PermissionUsed for
instagram_business_basicYour username, picture, follower count, account ID
instagram_business_content_publishPublishing Reels
  1. At developers.facebook.com/apps → Create app → choose the Instagram use case (“Manage messaging & content on Instagram”) → app type Business.
  2. In the app: Use cases → Manage messaging & content on Instagram → Customize, or Instagram → API setup with Instagram (business) login. Not listed? Add it with Use cases → Add use case; if that option is missing, the app's type can't use it, so create a new app and pick the Instagram use case (type Business) when asked.
  3. Step Generate access tokens → Add account: log in with your Instagram account. If asked, accept the tester invite in Instagram (Settings → Website permissions / Apps and websites → Tester invites).
  4. Click Generate token next to your account, approve, and copy the token.
  5. Reelwright → Publish → Instagram → paste the token → Connect Instagram (the account ID is found automatically).
“Invalid Request: Request parameters are invalid: Invalid platform app” means the Meta/Facebook App ID was used where the Instagram App ID belongs (shown under API setup with Instagram login → Business login settings), or old scopes such as user_profile, user_media or instagram_basic were requested in this flow. Use the Generate token button above, or the Instagram App ID with the two scopes in the table.

Route B — Facebook Login (Instagram linked to a Facebook Page)

PermissionUsed for
instagram_basicReading your Instagram account
instagram_content_publishPublishing Reels
pages_read_engagementRequired by Meta for publishing through a Page-linked account
pages_show_listOnly to look up your Instagram account ID (step 4)
business_managementOnly if your Page is managed in a Meta Business portfolio (Business Suite): without it the token sees no Pages
ads_management, ads_readOnly if your role on the Page comes through Business Manager
  1. Link the Instagram account to a Facebook Page (Page settings → Linked accounts).
  2. Create a Meta app (type Business) and add Facebook Login for Business.
  3. Open Graph API Explorer: select your app, User Token, add the permissions above, Generate Access Token.
  4. Optional: Reelwright finds your Instagram account through your Page by itself. To look it up by hand, run me/accounts to get your Page ID, then <PAGE_ID>?fields=instagram_business_account; the id inside (usually starting 1784…) is the Instagram account ID. Don't use the ID from me: that's your Facebook user, and Meta answers “username field is deprecated”.
  5. Make the token long-lived: Access Token Debugger → paste → Extend Access Token.
  6. Reelwright → Publish → Instagram → paste the token (account ID optional) → Connect Instagram.
Tokens from both routes last about 60 days; when one expires, Reelwright marks Instagram posts “Needs connection” — paste a fresh token. With Standard access your app can publish to accounts that have a role on the app (yours). Publishing for other people's accounts needs Advanced access through Meta App Review. Meta allows 100 API posts per account per 24 hours.

OBS (optional)

  1. In OBS: Tools → WebSocket Server Settings → Enable WebSocket server (port 4455), and keep authentication on.
  2. Show Connect Info → copy the server password.
  3. Reelwright → OBS link → Connect OBS directly: the PC's address, port and password. OBS on another PC: also allow port 4455 through that PC's firewall, and either map its recording folder or use the Relay (instructions on the OBS link page).

Public Terms and Privacy Policy URLs

TikTok and Meta ask for public links to your Terms of Service and Privacy Policy (Google asks for a privacy policy before verification). Reelwright includes both: fill in the highlighted placeholders in reelwright/static/legal/terms.html and privacy.html, publish the two files on any public static host (for example GitHub Pages), and use those URLs in each portal.
